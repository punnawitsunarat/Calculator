# การเทียบลำดับกดปุ่ม

แหล่งอ้างอิง: [เพลย์ลิสต์ 35 คลิป](https://www.youtube.com/playlist?list=PLqYbmGQRT_i1-h9FiJZkTY1p0BY_BgEBV) และ [คู่มือ CASIO](https://support.casio.com/pdf/004/fx-5800P_E.pdf)

แยกการตรวจภาพจากวิดีโอออกจากการทดสอบตามคู่มือ ตารางนี้ไม่ใช่คำยืนยันว่าดูครบทุกคลิปแล้ว

| หัวข้อ / คลิป | หลักฐานที่ตรวจ | ผลและช่องว่าง |
|---|---|---|
| Contrast `_uIl0xXlg_0` | ภาพวิดีโอช่วง 1:10 + คู่มือ E-9 | LIGHT/DARK, ลูกศร, บันทึกค่า |
| CALC `vj9czdpNjgs`, `OOYXrNTFW7I` | คู่มือ E-91, ทดสอบ 3A+B ได้ 18 และ 25 | ลำดับแทนค่าซ้ำผ่าน; ยังต้องเทียบโจทย์และภาพทุกช่วงของคลิป |
| SOLVE `o1GsVCGYZb8`, `tpu1sLIP10o` | ทดสอบ X²=4 ด้วยค่าเริ่มต้นบวก/ลบ | ได้ราก 2 และ −2; ยังต้องเทียบคลิปโดยตรง |
| EQN `oObXQlU_FQ8`, `AW_c8_LMX3w`, `6XLqG7Aw6_c` | คู่มือ E-71–72 + ทดสอบปุ่มและ browser | ผลทีละค่า, EXIT/EXE กลับ coefficient เดิม, AC ล้างเซลล์; ยังต้องเทียบจังหวะ EXE หลังกรอกช่องสุดท้าย |
| TABLE `X5YUoAP20f4`, `r2N1B_hPP_I` | คู่มือ E-95–97 + โจทย์ดอกเบี้ย + browser | แสดง X/F(X), เลือกเซลล์, เก็บสูตร/ช่วงเมื่อย้อนกลับ; หน้าช่วงยังเป็น wizard ไม่ใช่หน้ารวมแบบเครื่องจริง |
| Pol/Rec `uoNKnLCGKpk` | คู่มือ E-48 + unit tests | เก็บ I/J โดยไม่แก้ X/Y; ยังต้องเทียบหน้าจอจากคลิป |

ชุดทดสอบอยู่ใน `Tests/reference_workflows.test.cjs` ร่วมกับ tests ของ engine/device/LCD

หัวข้อที่ยังรอเทียบจากเพลย์ลิสต์: การใช้งานเบื้องต้น, อินทิกรัล/อนุพันธ์อันดับสอง, factorial, จำนวนเชิงซ้อน, ENG/prefix, FIX/SCI/NORM, BASE-N, การบันทึกสูตร, constants, ตัวอย่างวงจร/แรง/โมเมนต์ และคลิปแอป Android ซึ่งต้องแยกจากหลักฐานเครื่อง CASIO จริง

ข้อจำกัดที่ยังไม่ปิด: คลังสูตร 128 สูตร, ภาษาโปรแกรมทั้งหมด, ค่า constants รุ่นเดิม, numerical edge cases และความตรงของ LCD ระดับพิกเซล ดู `COMPATIBILITY.md` ประกอบ
