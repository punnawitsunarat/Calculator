# ติดตั้ง CaL บนหน้าจอโฮม iPhone

1. รัน `node Preview/build.cjs` ได้ชุดเว็บ static ใน `dist/`
2. อัปโหลดไฟล์ภายใน dist ไปที่ root ของเว็บ HTTPS ไม่ต้องใช้ Node server บนโฮสต์
3. เปิด URL HTTPS จาก Safari บน iPhone รอให้หน้าและไฟล์ออฟไลน์โหลดเสร็จ
4. แตะแชร์ → เพิ่มไปยังหน้าจอโฮม → เปิด “เปิดเป็นเว็บแอป” หากมีตัวเลือกนี้ → เพิ่ม
5. เปิดจากไอคอน CaL แล้วทดสอบเปิดอีกครั้งโดยปิดอินเทอร์เน็ต

localhost/127.0.0.1 ของคอมไม่ใช่ URL สำหรับ iPhone ยังไม่มีการเผยแพร่เว็บจากโปรเจกต์นี้

ไม่ต้องสมัคร Apple Developer สำหรับการเพิ่มเว็บลงหน้าจอโฮม มี manifest, ไอคอน PNG, standalone และ safe area สำหรับ iPhone แล้ว

ระบบ offline cache เก็บเฉพาะไฟล์แอป ตัวแปรและโปรแกรมยังอยู่ใน localStorage ของเบราว์เซอร์/เว็บแอป ไม่ส่งข้อมูลไปเซิร์ฟเวอร์ การล้างข้อมูลเว็บไซต์หรือระบบลบพื้นที่จัดเก็บอาจทำให้ข้อมูลหาย และข้อมูลจาก Safari อาจไม่ตามไปยังเว็บแอปที่ติดตั้ง

ทุกครั้งที่แก้โค้ด ให้ build ใหม่ก่อนอัปโหลด build script เปลี่ยนชื่อ cache จากเนื้อหาไฟล์ เมื่อมีเวอร์ชันใหม่ จะรอให้ปิดหน้าต่างเว็บแอปเดิมทั้งหมดก่อนสลับเวอร์ชัน เพื่อไม่รบกวนงานที่กำลังคำนวณ โฮสต์ควรให้ sw.js ตรวจอัปเดตได้โดยไม่ cache ระยะยาว

ตรวจ bundle และ offline handler อัตโนมัติด้วย `node --test Tests/pwa.test.cjs` ยังต้องตรวจการติดตั้งและออฟไลน์บน Safari/iPhone จริง

คู่มือ Apple: https://support.apple.com/en-gb/guide/iphone/iphea86e5236/ios
